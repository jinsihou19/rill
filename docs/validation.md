## 尚未验证与已知边界

- 未运行远端 TLS 成功连接、自定义证书/mTLS、外部 SSH 隧道、Redis 6.2/7.x/其他 8.x 版本矩阵。
- 未做 macOS 14 实机、Intel、浅色/高对比度/VoiceOver 全量验收。界面使用系统动态颜色和无障碍标签，但这不等于完整辅助功能认证。
- 未做百万键、超大集合、弱网、长时间运行、多日内存或真实生产负载测试。
- 文件导出保留原始字节的结构已核对，Stream 二进制保留有集成测试；未逐一人工操作所有原生文件面板和所有集合编辑菜单。
- 开发日志中见到启动时一次 AppKit `NSTableView` 重入警告；当前界面验收没有出现崩溃或操作失败，仍需在后续 macOS 兼容性回归中检查。
- 单帧 32 MiB 和字符串预览 1 MiB 为主动边界；超大单个集合元素仍可能触发响应限制，届时连接关闭并报告错误。
- 本构建未做 Developer ID 签名、公证、App Store 上传或自动更新。当前是可运行的开发版，不应视为生产规模和全平台兼容性已验证。

后续重点先验证真实使用环境中的 TLS、最低系统版本和大库交互，再扩展内建 SSH、Cluster/Sentinel 等拓扑能力。
