## R01：精确键查找

- 增加“模式 / 精确键 / Hex 键”三种明确入口，精确键不解释 glob、转义或空白；Hex 支持原始二进制和空键。
- 通过 TYPE/PTTL 定位键，匹配后自动打开详情。收藏菜单直接按原始字节定位，不要求先扫描到该键。
- TYPE 权限错误保留为错误，不伪装成键不存在。查询中已删除的键返回无结果；连接仍保持响应对齐。
- 新增 3 项自动测试。独立随机端口 Redis 写入 100,000 个键，精确已有/缺失查询共执行 2 次 TYPE、2 次 PTTL、0 次 SCAN；覆盖字面通配符、中文、空白、反斜杠、空键、二进制和受限 ACL。
- `swift test`：25 项，0 失败、0 跳过；`scripts/build-app.sh`：Release 构建及签名检查通过。
- 原生 UI 在独立演示实例上确认：选择精确键、提交 `app:settings` 后只显示该键并自动打开 JSON 详情。没有连接已有 6379。

验证环境沿用 [首版环境](../validation.md)。上述命令数量是本次真实集成测试结果，不是产品之间的性能排名；远端弱网和最低系统版本未在此项重新验证。
