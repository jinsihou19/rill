## R01：精确键查找

- 增加“模式 / 精确键 / Hex 键”三种明确入口，精确键不解释 glob、转义或空白；Hex 支持原始二进制和空键。
- 通过 TYPE/PTTL 定位键，匹配后自动打开详情。收藏菜单直接按原始字节定位，不要求先扫描到该键。
- TYPE 权限错误保留为错误，不伪装成键不存在。查询中已删除的键返回无结果；连接仍保持响应对齐。
- 新增 3 项自动测试。独立随机端口 Redis 写入 100,000 个键，精确已有/缺失查询共执行 2 次 TYPE、2 次 PTTL、0 次 SCAN；覆盖字面通配符、中文、空白、反斜杠、空键、二进制和受限 ACL。
- `swift test`：25 项，0 失败、0 跳过；`scripts/build-app.sh`：Release 构建及签名检查通过。
- 原生 UI 在独立演示实例上确认：选择精确键、提交 `app:settings` 后只显示该键并自动打开 JSON 详情。没有连接已有 6379。

验证环境沿用 [首版环境](../validation.md)。上述命令数量是本次真实集成测试结果，不是产品之间的性能排名；远端弱网和最低系统版本未在此项重新验证。

## R02：扫描预算与取消

- 增加独立扫描会话，保存已提交查询、游标、去重集及超页缓冲。修改搜索框但未提交不会污染续扫条件。
- 每轮最多显示 200 个键、8 次 SCAN、500 ms 协作时间预算；全轮最多保留 10 万个唯一键或 16 MiB 原始键名字节。时间预算在响应边界检查，不承诺中止服务端已执行命令；网络仍受连接超时约束。容量达到时提示缩小范围，不标为完整扫描。
- “停止”/Esc 只停止继续请求，已发出的回复读完并保留；继续时使用缓冲与原游标。新查询切换代次，旧回复不能写入新结果。
- 新增 5 项确定性会话测试和 1 项真实 Redis 测试，覆盖空页、重复、超页缓存、请求/时间/容量预算及暂停。650 个键续扫无丢失、无重复，停止后同一连接 PING 正常。
- `swift test`：31 项，0 失败、0 跳过；Release 构建和签名通过。
- 原生 UI：在合成演示实例上使用 CLIENT PAUSE 制造延迟，Esc 后出现继续扫描入口且连接保持；加载期间将 `not-found:*` 替换为 `app:*`，最终只显示两个 app 键，未被旧结果覆盖。
