# rill 使用指南

[项目首页](../README.md) · [文档目录](README.md)

rill 支持 Redis 6.2+ standalone，界面语言为简体中文。

## 连接与环境

点击「添加连接」或按 **⇧⌘N**，填写主机、端口、DB 与环境标识，按需设置 ACL 用户名、密码、TLS 和只读模式。连接测试返回实际服务器版本与延迟；选择连接后进入工作空间，右上方 DB 控件用于切换数据库。

初次选择生产环境时默认开启只读。关闭只读后，写入操作仍需准确输入连接名称确认。只读限制同时作用于界面操作和命令工作台；客户端保护应配合服务端 ACL 使用。

TLS 使用系统信任链验证证书。目前没有自定义 CA、客户端证书或跳过验证的配置界面。Cluster / Sentinel 路由和内建 SSH 隧道尚未提供。

## 查找与组织键

### 三种查找方式

按 **⌘F** 聚焦搜索框，在右侧选择查找方式，输入后回车：

| 方式 | 示例 | 行为 |
| --- | --- | --- |
| 模糊 | `user` | 分批扫描当前 DB，查找包含该字面片段的键；`*`、`?` 等按普通字符处理 |
| 模式 | `user:*` | 使用 Redis glob `MATCH` 语义 |
| Hex | `75 73 65 72 3A 31` | 按原始字节直接定位 `user:1`，不扫描全库 |

这里的“模糊”是键名片段匹配，不是拼写纠错。Hex 适合二进制键或无法直接输入的键名。

清空输入会立即恢复列表；所有方式下的空输入均浏览全部键，同时保留类型与收藏筛选。切换查找方式会重新查询。旧版精确搜索及其保存项会转为模糊搜索，保留原始关键词。

### 分批加载与停止

键扫描每轮受到结果数、请求数和时间预算限制。当前轮结束不一定意味着全库搜索完成；继续扫描可获得更多匹配结果。点击「停止」或按 **Esc** 暂停，随后可以继续。已发出的响应会读取完成，再保留游标和结果，避免破坏连接。

类型筛选优先使用 `SCAN TYPE`；服务端不支持时，在预算允许的扫描结果中检查类型。`SCAN` 不是一致性快照，扫描过程中发生的变更可能影响结果。

列表先显示键名，只为可见行获取类型和 TTL；隐藏对应列后不再发出该列的查询，滚回已查看位置可复用本轮缓存。可选元数据权限不足时显示未知及原因。

### 命名空间、收藏与保存搜索

- 命名空间支持多层分组和自定义字面分隔符；右键分组按钮设置分隔符，空分段和二进制键仍保留身份。
- 分组计数、收藏筛选都只反映已加载键；收藏跳转可以直接定位目标键。
- 展开状态、最近查询、选中键、显示与解码偏好按连接和 DB 保存。
- 保存搜索可以复用常用条件，每个工作空间最多保存 20 项。

命名空间达到资源上限时保留完整后缀，并提示当前范围；不会为了展示目录而丢弃键身份。

## 查看与编辑数据

### String

选择键后可切换文本、JSON 与 Hex。JSON 格式化仅改动草稿中的空白布局，保留数字文本、字段顺序和重复字段。Base64、Gzip 及组合解码用于查看编码后的文本；保存前可查看逆向编码后的写入字节数。

按 **⌘S** 或点击保存时，rill 检查服务端原始值是否仍与读取时一致，并保留 TTL。键已删除、类型变化或原值冲突时拒绝本次修改。离开未保存草稿前会提示。

字符串预览上限为 1 MiB，超限不可保存；解码后仍为二进制的内容只读。预览显示与编码转换不会自动写回 Redis。

### 集合与 Stream

Hash、List、Set、ZSet 使用可调整列宽的成员表格；按类型提供成员新增、修改、删除等操作。Hash / Set / ZSet 支持服务端 `MATCH`；List 的过滤仅作用于已加载内容。

Stream 默认从最新条目开始，可切换读取方向、设置 ID 范围，并查看字段和值。读取与导出保留原始字段字节和字段顺序。

成员读取同样有预算、停止状态和容量上限。集合编辑中的原值与结构检查用于拒绝已发现的冲突，不能替代服务端事务隔离或提供整个集合的一致性快照。

### 键操作

键操作菜单提供重命名、过期时间、删除、复制与导出。重命名使用 `RENAMENX`，同库复制使用不带 `REPLACE` 的 `COPY`，目标存在时拒绝覆盖；删除使用 `UNLINK`。

这些操作遵守只读与生产确认策略。可视化编辑中的部分原子检查需要服务端允许相关命令及 `EVAL`；权限不足时会返回实际错误。

## 命令工作台

按 **⌘2** 打开工作台。支持引号、转义与空参数；命令名补全保留已有参数，输入过程中可查看离线语法帮助。按 **⌘↩** 或输入框内回车执行。

工作台沿用当前连接的 DB、认证和只读设置，但使用专用 Redis 连接。连续命令复用连接，空闲 5 分钟后回收；切库、修改连接配置或认证信息时重建。界面分别显示连接准备与命令往返耗时。

### 历史记录

点击「历史」或按 **⌃R** 打开搜索弹层：

1. 输入关键词，列表实时过滤，并按最近使用排序。
2. 用 ↑ ↓ 选择，回车将命令填入输入框。
3. 检查参数后执行；Esc 或关闭按钮取消后，恢复原来的输入、光标和选区。

选择历史本身不会执行命令。重新打开弹层时恢复全部历史。每个连接 / DB 最多保留 100 条去重记录，只存在于当前应用会话，退出后清除。

### 执行范围

工作台限制会话切换、事务、订阅、阻塞、Lua / 函数执行和服务器管理命令，例如 `SELECT`、`MULTI`、`SUBSCRIBE`、`BLPOP`、`EVAL`、`CONFIG`、`FLUSHALL` 和 `KEYS`。切换 DB 使用应用控件。

只读模式仅接受明确识别为只读的命令；未知或模块命令按写入对待。发生超时或断线时不自动重放写入，结果可能未知，应刷新或独立查询核对。

## 服务器与慢查询

按 **⌘3** 查看服务器概览，按 **⌘4** 查看慢查询。

概览来自实际 `INFO` 响应。趋势需要主动开启，使用短窗口采集；内存分析对当前 DB 进行有预算的扫描，默认最多检查 1,000 个键、8 次扫描请求和 5 秒请求边界时间预算。

慢查询显示服务端阈值、单位和采集时间。服务器页列出相关命令的支持情况及权限错误。

趋势与内存分析使用独立任务连接，结束时回收；概览刷新与慢查询复用数据浏览连接。权限不足的可选信息显示未知与原因，其他获准操作可继续使用。

## 导出与复制

| 操作 | 范围 |
| --- | --- |
| 当前页导出 | 仅包含当前已加载内容 |
| 完整导出此键 | 分段读取单个键，输出带版本、完整性标记和摘要的 JSONL |
| 复制到新键 | 当前连接、当前 DB 内的服务端 `COPY`，拒绝覆盖 |

完整导出使用独立连接并支持停止，先写入权限 `0600` 的 `.partial` 文件，完成后再原子替换目标文件。停止或读取失败时保留不完整文件，原有目标不受影响。

使用下面的命令离线检查格式、Base64、数量及摘要：

```sh
python3 scripts/verify-export.py /path/to/key.jsonl
```

`complete: true` 表示本次读取流程完整，不证明一致性快照。当前没有导入入口；Stream 消费组、PEL、Hash 字段 TTL 和模块内部状态等不在导出范围。完整规则见 [单键导出格式](key-export-format.md)。

## 数据存储与资源上限

| 内容 | 位置与生命周期 |
| --- | --- |
| 连接配置 | `~/Library/Application Support/Rill/connections.json`，不含密码，文件权限 `0600` |
| 密码 | macOS Keychain，service 为 `app.rill.redis.credentials` |
| 收藏与浏览偏好 | 应用 UserDefaults；浏览偏好按连接和 DB 区分 |
| 命令历史与慢查询显示 | 仅内存，退出后清除 |
| 本地演示数据 | 随机端口、独立临时目录，退出演示应用后清理 |

产品显示名为 `rill`；为兼容已有连接，存储目录中的 `Rill`、Bundle ID 与 Keychain service 保持不变。

| 默认上限 | 数值 |
| --- | --- |
| 键扫描单轮 | 200 个结果、8 次请求、500 ms 请求边界时间预算 |
| 键名缓存 | 100,000 个键或 16 MiB 原始键字节 |
| 成员读取缓存 | 10,000 个成员或 16 MiB 原始成员字节 |
| String 预览 | 1 MiB |
| RESP 帧 | 32 MiB |
| 完整单键导出 | 256 MiB 文件、1,000,000 条记录、10,000 页、60 秒请求边界时间预算 |
| 单条导出 JSONL | 1 MiB；String 按 256 KiB 原始块读取 |

扫描与导出的时间预算在响应边界检查，不是硬实时期限；在途请求仍受连接超时约束。`SCAN COUNT` 是服务端提示值，不能保证每次返回固定数量的键。单个过大成员仍可能触发响应或导出限制。

## 检查和安装更新

从 **rill 菜单 → 检查更新…** 或 **设置 → 更新** 操作。默认每天静默检查，发现新版后侧栏显示入口；更新说明随安装窗口展示。存在未保存草稿、进行中的操作或编辑弹窗时，安装会暂缓，处理完成后由你再次点击继续。更多说明见 [更新与发布](updates.md)。

## 常见问题

**为什么查找后没有立刻看到所有匹配键？** 结果按预算分批读取，继续扫描可获取更多内容。收藏筛选和目录计数也只基于已加载数据。

**为什么 TTL 或内存显示未知？** 可能是相关命令被 ACL 拒绝或服务端不支持。查看提示中的实际原因，不应把未知理解成永久键或零内存。

**为什么某些键不能保存？** 检查是否只读、是否二进制或超出预览上限，以及服务端是否发生原值冲突或权限拒绝。

**超时后可以直接重试写入吗？** 先刷新并核对实际结果。Redis 可能已执行请求，只是客户端没有收到响应。

**完整导出可以当作备份或迁移吗？** 这是有明确范围的单键分段读取，尚未提供导入或全库迁移能力；一致性与排除状态见格式文档。
