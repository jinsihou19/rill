# Rill v0.2.0 新增功能与安装说明

日期：2026-11-02。版本类型：macOS 14+ / Apple Silicon 本地开发版。Bundle ID 继续使用 `app.rill.redis`；配置与 Keychain 服务沿用既有位置。

## 相对 v0.1.0 新增

| 使用场景 | 本轮变化 |
|---|---|
| 快速找键 | 明确区分 glob 模式、字面精确键和 Hex 原始键；精确键不扫描全库，收藏可直接跳转 |
| 大库浏览 | 扫描有请求/时间/容量预算，可暂停与继续；仅加载可见行需要的类型/TTL，隐藏列不查询 |
| 权限受限的服务器 | 可选元数据逐项降级，未知 TTL/总数不假装为零或永久；显示实际观察到的能力和原因 |
| 业务键组织 | 多层命名空间、自定义分隔符、原始字节稳定身份；展开状态按连接和 DB 保存 |
| String 编辑 | 文本/JSON/Hex 与草稿分离；无损 JSON 格式化保留大数、顺序及重复字段；Base64/Gzip/组合解码、逆向编码后的字节预览，保存继续检查原值并保留 TTL |
| 高频工作台操作 | 独立连接复用、准备/往返分别计时；离线语法帮助、保留参数的命令名补全、可搜索去重内存历史 |
| 重复查询 | 保存搜索，按连接/DB 恢复查询、选中键、显示/解码偏好 |
| 集合与事件排查 | Stream 默认最新优先，支持双向与 ID 范围；Hash/Set/ZSet 服务端 MATCH，List 明确过滤已加载内容；成员读取可停止并有预算 |
| 诊断 | 慢查询阈值/单位/采集时间；主动开启的短窗口趋势与有范围的内存分析，任务使用独立连接 |
| 数据带走与复制 | 版本化完整单键 JSONL 导出，包含二进制、绝对过期策略、完整性和摘要；同库 COPY 默认拒绝覆盖 |
| 本地性能 | 增量 RESP 分帧、后台高亮/转换、有界结果预览及快速 Hex 输出 |

逐项实现与验证证据见 [迁移实施记录](../research/implementation-log.md)，导出格式及排除范围见 [格式说明](../key-export-format.md)。

## 打包与安装

构建入口仍为 `scripts/build-app.sh`。本次从同一源码生成 v0.2.0 的 Release 应用，归档为 `build/Rill-v0.2.0-macOS-arm64.zip`，安装目标为 `/Applications/Rill.app`。安装时保留旧应用副本，既有连接配置、收藏/偏好和钥匙串数据沿用。

本机 ad-hoc 签名，未做 Developer ID 签名或公证，不是 App Store 版本。
