# Rill v0.2.4 历史搜索取消修复

日期：2026-11-03。macOS 14+ / Apple Silicon 本地开发版，build 6。

- 修复取消历史搜索后命令被全选，继续输入会覆盖整条草稿的问题。打开历史前保存光标和选区，按 Esc 或点击关闭后恢复原编辑位置。
- 使用原生 UTF-16 选区保留中文、Emoji 和选中文本的替换行为；命令已改变、输入框已移除或切换工作区时，不套用旧选区。
- 历史选择仍只填入命令，由用户决定执行。重复按 ⌃R 不覆盖首次保存的编辑位置。

## 验证

2026-11-03 核心 83 项测试通过；新增 AppKit 测试目标的 4 项回归通过，覆盖行尾/中间光标续写、中文与 Emoji 选区替换、拒绝过期命令快照，以及没有默认窗口字段编辑器的自定义编辑器。合计 87 项，0 失败。

随机端口独立 Redis 库的实际窗口回归通过：`GET app:ver` → 历史 → Esc → 输入 `sion`，得到 `GET app:version`；用鼠标打开并关闭后，在命令中间插入 `:`，位置正确；原选区 `用户:🔑` 在重复按 ⌃R 和 Esc 后仍被保留，替换得到 `GET other`。

历史选择仍只填入：预先执行一次 `INCR qa:p2-proof`，从历史填回命令后，后台计数仍为 1。Release 构建与严格签名检查通过。

## 打包

版本为 v0.2.4 / build 6，安装路径 `/Applications/Rill.app`，归档 `build/Rill-v0.2.4-macOS-arm64.zip`。连接配置和钥匙串服务沿用，保留旧应用备份。本机 ad-hoc 签名，未做 Developer ID 签名或公证。

原生选区处理通过 [窗口第一响应者](https://developer.apple.com/documentation/appkit/nswindow/firstresponder) 定位实际字段编辑器，使用 [文本选区恢复](https://developer.apple.com/documentation/appkit/nstextview/setselectedrange(_:affinity:stillselecting:)) 保留原编辑位置；沿用现有 SwiftUI 命令输入框。
