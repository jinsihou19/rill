# rill v0.2.5 应用内更新与代码审核

日期：2026-11-03（Asia/Taipei）。macOS 14+，build 7。

## 新功能

- 参考 CodexMeter 接入 Sparkle 2.10.1：每天静默检查、侧栏新版提示、菜单与设置检查入口，原生窗口展示更新说明并下载安装。
- 更新源和安装包使用 rill 独立 Ed25519 密钥签名；草稿、写入、命令、导出和未完成的编辑会阻止重启，处理后由用户主动继续。
- 新增 Universal 签名发布脚本及手动触发的 GitHub Release / appcast 工作流。普通推送不自动发布。

## 修复与整理

- 修复 Sparkle 将“没有新版本”和用户取消安装也送入结束回调时，更新状态误报检查失败的问题；真实网络错误继续保留失败提示。
- 产品显示名、窗口、Swift 可执行产品、构建产物和演示统一为 `rill`。内部 `RillCore` / `RillApp` 模块名、Bundle ID、连接配置目录和 Keychain service 保持兼容。
- 修复新建键指定 TTL 时，`PEXPIRE` 权限拒绝或绝对时间溢出会留下永久键的问题。Lua 内在创建前对不存在的目标检查过期命令；失败时不创建键。
- 修复详情读取中切换搜索条件后，旧加载与停止状态没有释放，导致工作区持续忙碌的问题。旧响应仍读取完成，通过代次校验丢弃。
- 区分网络传输失败和本地校验 / 服务端拒绝。界面写入断线后明确显示“写入结果可能未知”，不自动重试，并保留提示不被随后到达的断线通知覆盖。
- 修复 List 的已加载内容过滤词跨键残留，切换键时清空过滤和成员选择。
- 收录新版首页、真实演示截图、使用指南和架构说明，补齐 v0.2.4 及调研 / 迁移文档入口。
- 抽出共用的脚本化 Redis 测试服务，新增应用状态回归；增加 macOS GitHub Actions 测试与构建检查。

本轮验证结果、复现条件和未覆盖范围见 [代码审核记录](https://github.com/jinsihou19/rill/blob/main/docs/audits/2026-11-03.md)。

本机构建命令为 `./scripts/build-app.sh`，产物为 `build/rill.app`。采用本机 ad-hoc 签名，未做 Developer ID 签名、公证。实际在线升级需要先发布新的签名安装包。
