# Rill v0.2.2 命令历史交互说明

日期：2026-11-03。macOS 14+ / Apple Silicon 本地开发版，build 4。

- 将“历史”菜单和旁边的筛选输入框合并为一个历史弹层。点击“历史”或按 ⌃R 打开，自动聚焦搜索；命令及参数实时筛选，显示匹配数和当前连接 / DB。
- 最近使用的命令排在最上面，重复命令合并；长命令提供两行预览，填入时保留完整原文。
- ↑↓ 选择，回车或点击记录填入命令框；Esc 关闭并保留原输入。选择历史不会执行命令，弹层打开时执行按钮不可用。
- 无历史与无匹配分别提示；可清空筛选恢复结果。每次重新打开显示全部历史，避免残留筛选条件。
- 弹层高度随记录数量收缩，命令执行结束后焦点回到命令框，便于连续操作。

历史保持按连接和 DB 隔离、最多 100 条、单条 16 KiB、仅本次应用会话的边界，不写入磁盘。

## 验证

2026-11-03 全量 83 项自动测试通过，0 失败、0 跳过。新增历史筛选用例覆盖最近使用排序、大小写、中文、搜索两端空白、无匹配、去重及保留原命令内容。Release 构建与严格签名检查通过。

在随机端口独立 Redis 测试库中完成原生交互回归：⌃R 自动聚焦、实时筛选、↑↓ 选择、回车和鼠标填入、Esc 保留当前输入、无历史/无匹配提示、重新打开清空筛选、弹层高度和执行后连续输入。验证 DB 1 历史为空，切回 DB 0 后保留原有两条历史。

专门执行一次 `INCR qa:history-proof`，随后用回车和鼠标从历史填回该命令，并在弹层中按 ⌘↩；后台计数始终为 1，确认这些选择操作没有重复执行写入。最终构建重新验证后仍为 1。
