# Rill v0.1.0 首版交付说明

日期：2026-10-30。版本类型：本机 Apple Silicon 开发版。本地 Git 标签：`v0.1.0`。

## 交付内容

- SwiftUI/AppKit 原生 macOS 应用，Network.framework 直连 Redis，密码保存到 Keychain。
- 多连接、环境标识、ACL、系统信任证书 TLS、连接测试、数据库切换、只读与生产写入确认。
- SCAN/MATCH/TYPE 分页、前缀分组、收藏，六类常见数据浏览与常用编辑。
- JSON/Hex、String 原值冲突检查和 TTL 保留、集合成员操作、键重命名/过期/删除、当前已加载页导出。
- 独立连接命令工作台、命令名称建议和内存历史、INFO 概览、最近 50 条慢查询。
- 原生菜单、快捷键、可调整栏宽、系统颜色、未保存修改提醒和退出保护。

## 构建与验证

运行和构建说明见 [项目 README](../../README.md)。可运行产物为 `build/Rill.app`，可分发的本地归档为 `build/Rill-macOS-arm64.zip`；构建产物不提交到 Git，可从源码重建。

首版已完成 22 项自动测试、原生存储检查、Release 构建和主要界面流程验收。环境、证据范围和未验证项见 [验证记录](../validation.md)。本说明引用该次实际验证结果，不代表后续改动自动通过验收。

## 首版边界

当前聚焦 standalone；内建 SSH、Cluster/Sentinel、完整多层键树、全库导入导出、Pub/Sub、模块专用编辑器和高级分析后置。远端 TLS、最低系统版本、多版本 Redis、大规模负载和正式分发尚未完成验收。

第一轮研究主要来自公开说明与官方协议文档，已吸收核心工作流。后续源码深入研究用于判断值得迁移的细节，不直接扩大本标签代表的产品能力。

## 本地版本管理

`v0.1.0` 固定本次首版代码与文档。研究报告可在后续文档提交中更新；除非另外开始实现任务，研究阶段不修改 `Sources/`、`Tests/`、构建配置或应用行为。
