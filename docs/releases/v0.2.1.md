# Rill v0.2.1 搜索修复说明

日期：2026-11-03。macOS 14+ / Apple Silicon 本地开发版，build 3。

- 增加“模糊”查找，新工作区默认使用：输入键名片段后按回车即可查找包含该片段的键。中文、空格、`*`、`?`、方括号和反斜杠保留字面含义。
- 修复用退格键删空搜索框后仍停留在旧结果的问题。删空或点击清除都会立即重查；所有查找方式的空输入均恢复浏览，并保留类型和收藏筛选。
- 切换查找方式会立即重新查询，保留未保存草稿提醒。模式、Hex 键及保存搜索继续可用。
- 查找方式收进输入框右侧，同一行提供 `≈` 模糊、`.*` 模式、`0x` Hex 键三个按钮；选中状态高亮，悬停显示说明，并提供辅助功能标签。
- 取消独立的精确搜索入口；旧版工作区及保存项中的精确搜索自动转为模糊搜索，关键词原样保留。Hex 键及收藏跳转继续直接定位键。

模糊查找使用服务端 SCAN/MATCH，沿用分页、停止/继续和容量预算。它匹配字面片段并区分大小写，不提供拼写纠错；数据库较大时可能需要继续扫描。

## 验证

2026-11-03 执行全量 82 项自动测试，0 失败、0 跳过。新增测试覆盖字面片段转义、中文/二进制键、无结果后重置扫描、各模式空输入和类型筛选。配置/Keychain 合成检查通过，并验证旧精确查询和保存项迁移到模糊查询后关键词保持原样。

随机端口独立 Redis 库的原生回归通过：默认模糊搜索；`user` 匹配前缀和中间片段共 5 个键；中文、特殊字符查找；无结果后退格删空恢复 19 个键；模式切换立即刷新；清除后仍保留 Hash 筛选并恢复 3 个键；Hex 直接打开 `user:1001` 详情。最终界面在输入框右侧显示三个按钮，已检查选中状态、辅助功能标签和实际窗口布局。

Release 构建及严格签名检查通过。此轮不代表弱网、大库性能或所有 macOS 版本均已验收；沿用既有分批扫描预算。
