# Rill v0.2.3 成员列宽修复说明

日期：2026-11-03。macOS 14+ / Apple Silicon 本地开发版，build 5。

- 移除集合成员表第一列原有的 250 点最大宽度，可通过表头分隔线继续拖宽。
- Set 的 Member 列使用更宽的默认布局，“字节”列调整为 64–120 点，将空间留给成员内容。
- Hash、List、ZSet、Stream 共用的第一列也解除固定上限；保留这些类型的 Value / Score 列原有宽度策略。

## 验证

2026-11-03 Release 构建及严格签名检查通过。使用随机端口独立 Redis 库，打开包含 14 个成员的 Set，覆盖序列化二进制字符串及长文本。确认默认 Member 列已宽于旧上限，并实际将表头分隔线继续向右拖动成功。

切换至 Hash，确认 Field / Value 两列恢复对应布局；实际拖动 Field 列超过旧上限后，Value 内容仍正常可见。拖动前后 Set 成员数及 DUMP 摘要一致，原始二进制数据未改变。

本轮为列宽布局修改，执行了构建和原生交互回归，没有新增或重跑核心逻辑测试；未逐一验收 List、ZSet、Stream 的拖动交互。
